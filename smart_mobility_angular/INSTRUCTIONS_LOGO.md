# Instructions pour ajouter le logo CityBrain

## Étapes :

1. **Enregistrez l'image** que vous avez envoyée sous le nom :
   ```
   citybrain-logo.png
   ```

2. **Placez l'image** dans ce dossier :
   ```
   smart_mobility_angular\src\assets\citybrain-logo.png
   ```

3. **Créez le dossier assets** s'il n'existe pas :
   ```bash
   mkdir src\assets
   ```

4. **Redémarrez le serveur Angular** :
   ```bash
   Ctrl + C
   ng serve
   ```
