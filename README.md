# 🧠 CityBrain Analytics
**Urban Traffic Smart City Platform** — Esprit School of Engineering, DATAQUEENS team, PI-CDIO 2025–2026.

## About
CityBrain Analytics is a smart city platform that predicts urban mobility stress and analyzes traffic patterns using machine learning. It combines an Angular frontend, a Streamlit dashboard, and Python ML models.

## Features
- Accident hotspot detection using DBSCAN clustering
- CO₂ emissions forecasting with LSTM time-series
- Real-time traffic, environment & infrastructure dashboards
- Automated ETL pipeline with scheduled Airflow DAGs

## Methodology
Built following the **GIMSI methodology**: Identification → Design → Implementation → Continuous Improvement.


## Tech Stack
- **Frontend**: Angular
- **Dashboard**: Streamlit
- **ML Models**: Python (Jupyter Notebooks)
- **Data Warehouse**: Microsoft SQL Server
- **ETL**: Talend Open Studio
- **Orchestration**: Apache Airflow
- **Dashboards**: Power BI · Grafana
